# Семейный альбом — макет

Электронный альбом рода, который листается как книга. Сделан как макет оформления: важно, как
это выглядит и насколько удобно листать, а не реальные данные.

**Открыть:** https://valeonl.github.io/family-album/

## Что внутри

- Обложка, содержание со ссылками, пять страниц людей, разворот «что любили и не любили»,
  финальная страница.
- Страница человека: портрет, годы, кем приходится, факты, вкусы и привычки, цитата.
- Листается кнопками по краям, нижними кнопками, свайпом на телефоне и клавишами ← →.
- На компьютере — разворот из двух страниц, на телефоне — одна страница того же размера,
  что и экран. Кнопка в шапке переключает вид вручную.
- Перелистывание — настоящий поворот листа вокруг корешка, а не слайд.

## Чего здесь нарочно нет

- **Настоящих фотографий.** Портреты нарисованы кодом (градиент и инициалы): фотографии семьи
  в открытый репозиторий не выкладываются, а для макета важна форма кадра, а не лица. При
  подключении настоящих данных портрет заменяется обычной картинкой — место под неё уже есть.
- Сервера и сборки: это статические файлы (`index.html`, `styles.css`, `album.js`), поэтому сайт
  работает где угодно, включая GitHub Pages.

## Как заменить данные

Данные лежат одним списком `PEOPLE` в начале `album.js`. Страницы собираются из него функцией
`buildPages`, поэтому новый человек — это ещё один объект в списке, вёрстку трогать не нужно.
